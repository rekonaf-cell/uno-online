# ページワン Online

スマホのブラウザで複数人が離れた場所から遊べる、トランプ2組を使った「ページワン」オンライン対戦ゲームです。

## ローカルで動かす

```bash
npm install
npm start
```

`http://localhost:3000` を開きます。

## Renderへのデプロイ

1. このリポジトリをRenderの「New Web Service」で選択
2. Build Command: `npm install`
3. Start Command: `npm start`
4. デプロイ後に発行されるURLを、友達にも共有すればスマホから参加できます

## 遊び方

1. 一人が「部屋を作る」でルームコード(4桁)を発行
2. 他の人はそのコードを「参加する」に入力
3. 2人以上集まったらホストが「ゲーム開始」
4. 初回はサイコロ(2個)で親を決める。同点なら同点の人だけで振り直し。2ゲーム目以降は前のゲームで上がった人が親になる
5. 親が配る枚数(3枚以上)を選ぶと配札開始
6. 場と同じマーク・同じ数字のカードを出す。出せなければ山札を引く
7. 手札がなくなったら勝利(ジョーカーでは上がれない。8は場に合っている時だけ上がれる)

### 特殊カード

- **A(1)**: 次の人をスキップ
- **2**: 次の人は2枚ドロー。2を出して重ねると+2ずつ加算して次の人へ回せる
- **3**: 次の人は3枚ドロー。3で重ねられる(2と3は別系統で混在不可)
- **8**: マーク(スート)を変更。ただし出せるのは「マークが合っている時」か「場が8の時」のみ
- **J(11)**: 逆回り
- **ジョーカー**: どの場でも出せるワイルド。出したらマークを選べる。上がりには使えない

### ページワン宣言・ロン

- 残り1枚になったとき(ジョーカー・8以外)は「ページワン！」を宣言できる
- **ジョーカー・8以外の最後の1枚は、ページワンを宣言していないと自分の番が来ても出して上がることができない**(引くしかない)。宣言するかどうかは駆け引きとして自由
- **宣言できるのは次の人がカードを出す前まで**。自分が1枚になった後、他の誰かが1枚でもカードを出すとその回の宣言チャンスは消える(その後は引くしかなく、また1枚になった時に新しく宣言し直す必要がある)
- ジョーカー・8が最後の1枚の場合は宣言不要(そもそも宣言できない)。ジョーカーは自分の番が来るまでの間に誰かがカードを切ればロンで上がれる可能性があるが、誰も切らないまま自分の番が来たら引くしかない。8は「マークが合っている」か「場が8」の時だけ自分の番で出して上がれる
- 誰かが出したカードの数字と、自分の残り手札の合計が一致すれば、自分の番でなくても「ロン！」でその場で勝利(麻雀のロンと同様)。この合計判定ではA=1、J=11、Q=12、K=13で計算し、ジョーカーは好きな数字として扱える
- **フリテン**: ある数字でロンできたのに見送ると、自分の番が来るまでその数字では二度とロンできない(他の人が同じ数字を後から切っても不可)。自分の番が来る(引く・出す)とリセットされる

### 得点計算(上がった時)

- **通常の上がり**: 上がった人は、他の全員から「その人の残り手札の点数」を受け取る
- **ロン**: 上がった人は、当てられた人(切ったカードを出した人)からのみ、その人の残り手札の点数×2を受け取る(他の人からは受け取らない)
- **手札の点数の数え方**(通常の得点計算専用。ロンの合計判定とは別ルール):
  - A・3・ジョーカー: 10点
  - J・Q・K: 11・12・13点
  - 4〜10: そのままの数字
  - 2: それ自体は加算されず、2以外のカードの合計を2倍にする(2が2枚あれば4倍)
- 得点は部屋の中で累積され、「次のラウンドへ」でリセットせずに続けられる

### 親・配る枚数・ドスン

- **親**: 初回はサイコロ2個の合計が一番大きい人。同点は同点の人だけで振り直し。2回目以降は前のゲームで上がった人(通常・ロン・ドスンいずれも)が次の親になる
- **配る枚数**: 親が3枚以上の好きな枚数を指定できる
- **ドスン**: 配り終わった直後、最初に場に出たカードの数字と自分の手札の合計が一致していれば、まだ誰も行動していない(引く・出すをしていない)うちに「ドスン！」で即勝利できる。支払いは各自の手札合計×2を、それぞれが支払う(通常の上がりの2倍)。誰かが最初に行動すると、そのラウンドのドスンの機会は無くなる

### CPU(ボット)

- ロビー画面でホストが「CPUを追加」を押すと、CPUプレイヤーが1人増える(削除も可能)。1人でも2人目にCPUを入れてすぐ遊べる
- CPUは自分の手札とルールに従って自動でプレイする: 出せるカードがあれば出す(ワイルドは持っている枚数が多いマークを選ぶ)、無ければ引く。ロン・ドスンの権利があれば必ず取る。残り1枚になったら即座に「ページワン」を宣言する
- CPUの行動は毎回0.9秒ほど間を置いてから反映される(人間側がロン・ドスンで割り込めるように)
- ゲーム中はCPUの追加・削除はできない(ラウンドの合間かロビーでのみ可能)

### 捨て札履歴

- 場の下に、これまで出されたカードの履歴を新しい順に重ねて表示(省スペース、横スクロールで遡れる)
