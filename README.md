# ページワン Online

スマホのブラウザで複数人が離れた場所から遊べる、トランプ2組を使った「ページワン」オンライン対戦ゲームです。

## ローカルで動かす

```bash
npm install
npm start
```

`http://localhost:3000` を開きます。

## Renderへのデプロイ

1. このリポジトリをRenderの「New Web Service」で選択
2. Build Command: `npm install`
3. Start Command: `npm start`
4. デプロイ後に発行されるURLを、友達にも共有すればスマホから参加できます

## 遊び方

1. 一人が「部屋を作る」でルームコード(4桁)を発行
2. 他の人はそのコードを「参加する」に入力
3. 2人以上集まったらホストが「ゲーム開始」
4. 初回はサイコロ(2個)で親を決める。同点なら同点の人だけで振り直し。2ゲーム目以降は前のゲームで上がった人が親になる
5. 親が配る枚数(3枚以上)を選ぶと配札開始
6. 場と同じマーク・同じ数字のカードを出す。出せなければ山札を引く。山札から引いたら、そのカードが出せる場合でもそのターンは何もできず終了する
7. 手札がなくなったら勝利(ページワンを宣言済みの通常カードで上がれる。最後の1枚がジョーカーや8の場合は、自分の番では上がれない)

- 画面右上の「？遊び方」ボタンで、いつでもゲームの流れ・特殊カード・当たり・ページワン宣言・点数・コツをまとめた説明を開ける(項目ごとに開閉)

### 特殊カード

- **A(1)**: 次の人をスキップ
- **2**: 次の人は2枚ドロー。2かジョーカーを出して重ねると+2ずつ加算して次の人へ回せる
- **3**: 次の人は3枚ドロー。3かジョーカーで重ねられる(2と3は別系統で混在不可)
- **8**: マーク(スート)を変更。ただし出せるのは「マークが合っている時」か「場が8の時」のみ。最後の1枚が8の場合、自分の番でなくても誰かが8を出せば数字が一致するので「当たり！」で上がれる
- **J(11)**: 逆回り
- **ジョーカー**: どの場でも出せるワイルド。出す時はマークと「その時扱う数字」の両方を選ぶが、**選べるのは場のマークか数字のどちらか一方に合っている組み合わせだけ**(例: 場が「ハートの6」なら、ハートの好きな数字、または好きなマークの6は出せるが、関係のないマーク・数字の組み合わせ(ダイヤの9など)は宣言できない)。場に出た後はカードの背景(虹色)はそのままに、選んだマークと数字が表示され、以後はその数字として当たり・フリテンの対象になる。Aとして出せば本物のAと同じくスキップ、Jとして出せば本物のJと同じくリバースの効果が出る(2人対戦でAならもう一度自分の番)。上がりには使えない。2/3の連続中に出すと、その連続を+2/+3して次の人に回せる(この場合はマークは自由だが、数字はその2/3自身として扱われるため選べない。これは連続中の数字が常に場の数字と一致しているため上記の制約を自動的に満たす)。連続中でなくても、数字を2か3と指定して出せばそのまま新しく2/3を出したのと同じ扱いになり、次の人はその枚数を引くか2/3(かジョーカー)で対応しなければならない(この場合も上記のマーク・数字の制約は適用される)。なお、最初の場札そのものがジョーカーだった場合の宣言は、合わせるべき場がまだ存在しないため完全に自由。宣言した数字がA・2・3・Jなら、本物の最初の場札と同じ効果(スキップ・連続・リバース)がドンの受付後に出る。8として宣言した場合はマーク指定のみ

### ページワン宣言・当たり(ロン)

- 残り1枚になったとき(ジョーカー・8以外)は「ページワン！」を宣言できる
- **最後の1枚が8・ジョーカー以外の通常カード**: ページワンを宣言していないと、自分の番で出して上がることも、当たりを宣言することもできない(自分の番が来たら必ず引く)。宣言していれば出して上がれるし、当たりも取れる
- **最後の1枚が8の場合**: 宣言の有無にかかわらず、自分の番では上がれない。場に合っていれば出せるが、上がりにはならず手札0枚のままゲームが続く。0枚の人は次の自分の番で山札から1枚引き、手札が1枚になるので、ページワンを宣言するかどうかを選んでターン終了(0枚の間は当たりの対象にならない)
- **宣言できるのは次の人がカードを出す前まで**。自分が1枚になった後、他の誰かが1枚でもカードを出すとその回の宣言チャンスは消える(その後は引くしかなく、また1枚になった時に新しく宣言し直す必要がある)
- ジョーカー・8が最後の1枚の場合は、宣言していなければ当たりは取れる(自分の番では上がれない)。宣言すること自体は駆け引きのブラフとして自由にできるが、本来宣言してはいけない札なので、**宣言してしまうと当たりも取れなくなる**。ジョーカーは自分の番が来ても出せず引くしかない。8は自分の番で出せるが上がりにはならない
- 誰かが出したカードの数字と、自分の残り手札の合計が一致すれば、自分の番でなくても「当たり！」でその場で勝利(麻雀のロンと同様)。この合計判定ではA=1、J=11、Q=12、K=13で計算し、ジョーカーは好きな数字として扱える
- **誰かが上がりで出したカードにも当たれる**。上がろうとした人の出したカードで自分が当たれば、その上がりは成立せず、代わりに自分が当たりで勝利する(上がろうとした人は当たられた側として支払う)
- **複数人が同時に当たりの場合**: 該当する全員が上がりになる。カードを出した人(当てられた人)は、当たった人それぞれに手札の合計×2を個別に支払う。次の親は、当たった人同士のサイコロで決める(1人だけなら直接その人が親)
- **フリテン**: ある数字で当たっていたのに見送ると、自分の番が来るまでその数字では二度と当たりを宣言できない(他の人が同じ数字を後から切っても不可)。自分の番が来る(引く・出す)とリセットされる
- **当たり返し**: 自分が出したカードに誰かが当たった時、自分の残り手札の合計もそのカードの数字と一致していれば「当たり返し」ができる。当たり返すと、そのカードに当たっていた人たち(当たり返しされた側)がそれぞれ、自分の手札の点数×4を自分(元の当たられた側)に支払い、自分がそのラウンドの勝者になる。当たり返しをせず見送ることもでき、その場合は通常通り自分が当たられた側として支払う
- 宣言している間は、対戦相手一覧にそのプレイヤーが赤く光る枠と「📢ページワン！」の表示が出て、自分の欄にも同じ表示が出る

### 得点計算(上がった時)

- **通常の上がり**: 上がった人は、他の全員から「その人の残り手札の点数」を受け取る
- **当たり(ロン)**: 上がった人は、当てられた人(切ったカードを出した人)からのみ、その人の残り手札の点数×2を受け取る(他の人からは受け取らない。複数人当たりの場合は当てられた人がそれぞれに支払う)。このとき当てられたカード(切って当たられたカード)は当てられた人の手札に戻した上で点数計算する(2で当たられた場合はその2の効果で残り手札が2倍になる)。ただし2が最後の1枚(上がろうとして出した2)で当たられた場合は0点になってしまうため、当てられた人が山札から2枚引き、その2枚と当てられた2を合わせて計算する
- **手札の点数の数え方**(通常の得点計算専用。当たりの合計判定とは別ルール):
  - A・3・ジョーカー: 10点
  - J・Q・K: 11・12・13点
  - 4〜10: そのままの数字
  - 2: それ自体は加算されず、2以外のカードの合計を2倍にする(2が2枚あれば4倍)
- 得点は部屋の中で累積され、「次のラウンドへ」でリセットせずに続けられる
- 当たり・当たり返し・ドンで勝負がついた場合、勝った人の手札は結果画面で全員に公開される(合計がどう的中したか確認できる)
- 結果画面では、支払う側の手札を1枚ずつめくりながら点数が加算されていくアニメーションが流れる。2は必ず最後にめくられ、少し間を置いてから合計が2倍になる特別演出が入る

### 親・配る枚数・ドン

- **親**: 初回はサイコロ2個の合計が一番大きい人。同点は同点の人だけで振り直し。2回目以降は前のゲームで上がった人(通常・当たり・ドンいずれも)が次の親になる。複数人同時に上がった場合は、その人たちだけでサイコロを振って次の親を決める
- **配る枚数**: 親が「3枚」「4枚」「5枚」のボタンか、「その他」を選んで3枚以上の好きな枚数を指定できる
- **最初の場札が2・3の場合**: 親がそのまま通常時の2・3と同じ対応をする(2/3かジョーカーを出すか、指定枚数を引く)。ターンは親から始まる
- **最初の場札がAの場合**: 親がまず自分の番として通常通りカードを引くか出す。その後、次の人が1人スキップされる(Aを出した時と同じ効果が、親の番が終わった後に発生する)
- **最初の場札が8の場合**: 親がマークを宣言してから、ドンの受付・親の番が始まる(8を出す時と同じ)。親は自分でマークを選べるため、実質どんなカードでも出せる
- **最初の場札がジョーカーの場合**: 親がマークと数字の両方を宣言してから、ドンの受付・親の番が始まる。ジョーカー自体には数字がないため、宣言された数字が誰かドンで上がれるかどうかの判定基準になる。宣言した数字がA・2・3・Jならその効果も出る
- **2・3で上がった場合**: 上がった時点でその2/3(連続中ならその合計枚数)の効果は残っており、次の順番の人はその枚数を引く。得点計算はその後の手札で行われる
- **ドン**: (成立すると、パチスロ風の「フリーズ演出」が流れる: 暗転→静寂→光が走り、金色の爆発と「ドン！！」。画面タップで飛ばせる。50%の確率で、代わりに「プチュン」とブラウン管のように暗転して勝者の手札が上から1枚ずつ降ってきて着地する演出になる) 配り終わった直後、最初に場に出たカードの数字と自分の手札の合計が一致していれば、まだ誰も行動していない(引く・出すをしていない)うちに「ドン！」で即勝利できる。支払いは各自の手札合計×2を、それぞれが支払う(通常の上がりの2倍)。誰かが最初に行動すると、そのラウンドのドンの機会は無くなる。複数人同時にドンの場合は該当者全員が上がり、ドンしなかった人がそれぞれに支払う(ドンした人同士は支払わない)

### CPU(ボット)

- ロビー画面でホストが「CPUを追加」を押すと、CPUプレイヤーが1人増える(削除も可能)。1人でも2人目にCPUを入れてすぐ遊べる
- CPUは自分の手札とルールに従って自動でプレイする: 出せるカードがあれば出す(ワイルドは持っている枚数が多いマークを選ぶ)、無ければ引く。当たり・ドンの権利があれば必ず取る。残り1枚になったら即座に「ページワン」を宣言する
- CPUの行動は毎回0.9秒ほど間を置いてから反映される(人間側が当たり・ドンで割り込めるように)
- ゲーム中はCPUの追加・削除はできない(ラウンドの合間かロビーでのみ可能)

### 通信が切れた時の復帰

- 画面のスリープやアプリの切り替えなどで通信が一時的に切れても、再びアプリを開けば自動的に元のゲームに復帰できる(手札・得点・順番などすべてそのまま)
- 自分だけが切断してもゲーム自体は終了しない。切断中も他のプレイヤーからは見えており、しばらく(数分)は席が確保される
- 対戦中はできるだけ画面がスリープしないようにする(対応端末のみ。効かない場合もあります)

### テーブル表示

- カジノ風の円卓レイアウト。相手プレイヤーは円周に、自分は手前下に着席する形で表示され、手番のプレイヤーは金色に光って一目でわかる
- 各プレイヤーのアイコンには残り枚数のバッジが付き、相手・自分の手札枚数がぱっと見でわかる。親には「親」バッジが付く
- 回る方向(時計回り/反時計回り)はテーブル上部のバッジで表示され、リバースで切り替わると向きが反転する
- 山札はテーブル中央の邪魔にならない位置に小さく表示
- 捨て札履歴はテーブル中央にまとめて表示。現在のカードは大きく金枠付きで強調され、直近3枚までの履歴が右にずれながら重なって表示される(文字は隠れないよう右寄せ)
- カードを引く・出すたびに、山札⇔プレイヤーのアイコンの間をカードが飛ぶ演出と効果音が入る(誰の操作でも表示される)
- 当たり(ロン)で勝負がついた時は、当てた本人のアイコンから「そいよ」の吹き出しが一瞬出てから結果画面が開く
- 2/3の連続が4枚目以降になった時は、そのカードを出した人のアイコンから「容赦せんよ！！」の吹き出しが出る(5枚目以降も出した人ごとに続く)
- 吹き出しはアイコンからテーブル中央側に向かって表示される

### 3Dテーブル(three.js・斜め視点)

- テーブルの円卓、場のカード、山札、カードが飛ぶ演出だけを、three.js(`public/vendor/three.min.js`、MITライセンス)で斜めから見た形に描いている。席・吹き出し・手札・ボタンなどは従来どおりHTMLで、3Dの層は#roundTableの裏に敷く透明なcanvas(`public/table3d.js`)
- HTML側の席、自分の席、場札・山札の置き場所は、3Dの座標を画面の座標に変換して置く(奥の席は少し小さく、手前は少し大きくなる)。吹き出しなどは席の画面上の位置を基準にするので、そのまま追従する
- 軽くするための工夫: 影の判定(シャドウマップ)は使わず、柔らかい影の板で代用。常時描画はせず、カードが飛んでいる間だけ描き直す。描画の細かさは端末の2倍までに制限
- 逃げ道: three.jsが読み込めない、WebGLが使えない、描画コンテキストが失われた、カードが飛ぶ間のフレームが遅い(中央値55ms超)、「視覚効果を減らす」設定、のいずれかでは自動で3Dを切り、従来のHTMLの円卓(真上から見た形)のまま動く。遅くて切った場合は次回以降も切ったままにする(`?3d=on`を付けて開くと再度有効)。`?3d=off`で手動で切れる

### 見やすさ・操作しやすさ

- **場のマーク**: テーブル上に、いま場に出せるマークを大きなバッジで表示(めくれる演出の最中は隠れる)
- **自分の番の合図**: 自分の番になると、画面の縁が金色に光り、短い音と振動が鳴る。別のタブを見ているときはタブの題名に「【あなたの番】」が付く
- **残り枚数**: 相手の残りが1〜2枚になると、枚数バッジが赤く点滅する
- **ログ**: カードは色付きのマーク+数字で表示。直近3行は大きく、最新の1行は太字
- **スワイプで出す**: 出したいカードを上へスワイプしても出せる(従来の「1回タップで持ち上げ→もう1回タップ」も使える)
- **大きな操作ボタン**: 通す/当たり/ドンなどは大きく、位置を固定して押し間違えにくくした
- **出せない理由**: 出せないカードをタップすると、場のマーク/数字、連続中、ページワン未宣言、ジョーカーは最後の1枚で出せない、などの理由を具体的に表示
- **効果音・振動**: 自分の番、ページワン宣言(誰の宣言でも)、結果(勝ち/負け)に短い音と振動。「？遊び方」の中の「効果音・振動」で一括オフにできる(端末に記憶される)

### 手札の表示

- 手札が多くなると、カード同士が少しずつ重なって扇状に並ぶ(画面幅に収まらない分だけ自動で重なりが深くなる)
- 手札は大きめのカード。収まらないときは半分まで重ねて並べ、それでも多ければ手札の部分だけ横スクロールする
- 結果画面の「途中結果」ボタンで、これまでのラウンドごとの増減(当=当たり、返=当たり返し、ドン)と現在の得点を一覧で見られる
- ページワン宣言済みで最後の1枚のとき、上がる(出す)か引くかを決めると、約40%の確率で「伏せたカードがゆっくりめくれる」演出が全員の画面に出る。出した(上がり)なら表が開き、引いたなら閉じる。出したカードやログはめくれるまで隠される。演出が終わる(開く場合はカードが開く)まで、出した/引いた人の枚数とページワン宣言の表示は演出前のまま保つ(出した人の枚数が先に0枚になる・引いた人の枚数が先に増える、のを見せない)。引いた場合は番の移動・引く動きや音も見せず、次の人(CPU含む)の行動も約3.7秒待たせるので、上がりでないことが先に分からない。開いた場合は、他の人が「通す」か「当たり」を選び終わるまで開いたカードの画面のままで、当たりなら大きなギザギザの吹き出しで「そいよ！」と出てから結果画面に進む
- 出したいカードをタップすると一旦手前に大きくせり上がって確認できる(このタップはどのタイミングでも可能)。せり上がったカードをもう一度タップすると実際に出す。カード以外の場所(背景など)をタップすると、せり上がったカードは元に戻る

### 通す(パス)

- 誰かがカードを出す(または配り終わった直後)たびに、他の全員が「通す」を押すか当たり/ドンを宣言するまで、次の人のターンには進まない
- 通す必要がある間は、自分の手札を出したり山札を引いたりはできない(当たり・ドン・ページワン宣言は通す前でも可能)
- 当たり/ドンを宣言してもすぐには決着しない。他の全員が反応する(通す/宣言する)まで待ってから、その時点で宣言していた人たち全員が上がりになる
- CPUは、当たり・ドンできない場合は自動ですぐに「通す」を押す
